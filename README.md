# AI 产品拆解 Skill

一套可复用的 AI 产品拆解流程，附即梦图片生成、修改与下载的实测分析报告。

- **[拆解规则](SKILL.md)**：五层分析、分端取证和交付要求。
- **[即梦拆解报告](jimeng-report.md)**：测试结果、模型、人机分工、经济账与内嵌架构图。
- **[实测闭环与低额度模式](live-test.md)**：生成、修改、异常、下载和费用验证。
- **[最初提供的流程](original-workflow.md)**：方法来源存档。

## 规则与案例

`SKILL.md` 与其引用的规范文件是规则；`jimeng-report.md` 是案例，按需阅读，不覆盖规则。案例中的型号与结论只适用于2026-10-19的观察，不套用到新产品。

本公开仓库仅包含规则和报告，未上传浏览器截图、账户记录、历史操作日志或原始产物。

## 获取与使用

在线阅读直接点击上方链接；下载全部文件可选择 **Code → Download ZIP**。

作为Skill使用时，保留整个目录与内部相对路径，在支持本地Skill的工具中添加此目录，入口为 `SKILL.md`。

规则和案例可以分别修改，提交记录保留历史；已下载或安装的副本需要自行同步更新。

未另外指定开源许可证。
